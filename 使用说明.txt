刘旭脚本 使用说明
==================

授权说明：本软件由刘旭开发并授权使用，开发者可随时关闭使用。
  每次点"开始"时，软件会联网（访问 GitHub）验证授权；验证不通过或连不上网络时不能使用。
  停用只是不再运行自动化，不会删除或修改任何文件，也不影响在 Dachser 网站上手动操作。
  联系方式：xuliu00925@gmail.com

一、准备
  1. 电脑需要安装 Google Chrome。
  2. 整个"刘旭脚本"文件夹要放在一起使用，不要只拷贝 exe。
  3. 第一次运行如果 Windows 提示"已保护你的电脑"，点"更多信息" -> "仍要运行"。
  4. 第一次运行会打开 Chrome，请登录 Dachser，并让 Chrome 记住密码，以后会自动登录。

二、询价
  1. 功能选"询价"，选择询价表 Excel。
     表头需要有：编号、国家、邮编、城市、地址、数量、Unit/单位、单个物料（长/宽/高/重量）、
     Dangerous Goods Type/危险品类型、产品物料、是否需要尾板。
     "运费报价(欧元)"列合并的几行会合成一张询价单。
  2. 可以先勾"只预览"看托盘方案对不对，再取消勾选正式运行。
  3. 点"开始"，确认后脚本逐单填写 Enquiry 表单。
     每单填完请在浏览器里检查，然后自己点页面底部的 Enquiry 提交，脚本检测到结果页后自动做下一单。

三、建单
  1. 功能选"建单"，选择从领星导出的出库单 Excel。
  2. 脚本按"Remark/备注"里的 MR 编号，在 Dachser 的 My enquiries 里找报价：
     - 只找到一条：自动点 create
     - 找到多条：弹窗列出，请你在浏览器里自己选一条点 create，然后点"我点好了"
     - 没找到 / 已经 created：跳过
  3. 点 create 后脚本自动填写：收货地址 Street/Country/PCD/City（以领星为准，County 不改）、Name 1/2/3、联系人和电话、
     Order number 后加"+出库单号"、货物内容 battery、危险品 UN3480、上传危险品文件。
  4. 每单填完会弹窗，请在浏览器里检查，确认无误后自己点 Save，再点"继续下一单"。
  5. 结果表会保存在所选 Excel 旁边，文件名是"<Excel名>_建单结果.csv"，
     里面写了每单的处理结果和需要注意的地方。

四、危险品文件
  把危险品文件放进"危险品文件"文件夹（或在窗口里选别的文件夹）。
  文件名（不含扩展名）必须和领星表里的 SKU 完全一样，例如：
      SKU 是 11US2000ZZD-20001  ->  文件名 11US2000ZZD-20001.pdf
  找不到同名文件就不上传，并在运行记录里提醒。

五、产品托盘参数
  pallet_params.json 里是各产品的单箱尺寸、重量、每层个数、最大层数等。
  增加新产品时改这个文件即可（用记事本打开，保存为 UTF-8）。

六、其它
  - "停止"：当前这一单处理完后停止；如果正在等你操作，请在弹窗里点"结束"。
  - 脚本只填写，不会替你点 Enquiry / Save，提交前请务必检查。
  - 登录信息保存在 dachser_profile 文件夹里，删除它就需要重新登录。
