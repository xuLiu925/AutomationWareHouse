XL FreightPilot 使用说明
========================
Freight Quotation & Order Automation · Developed by Xu Liu（刘旭）

授权说明：本软件由刘旭开发。

一、准备
  1. 电脑需要安装 Google Chrome。
  2. 整个"XL FreightPilot"文件夹要放在一起使用，不要只拷贝 exe。
  3. 第一次运行如果 Windows 提示"已保护你的电脑"，点"更多信息" -> "仍要运行"。
  4. 第一次运行会打开 Chrome，请登录 Dachser，并让 Chrome 记住密码，以后会自动登录。

二、询价
  1. 功能选"询价"，选择询价表 Excel。
     表头需要有：编号、国家、邮编、城市、地址、数量、Unit/单位、单个物料（长/宽/高/重量）、
     Dangerous Goods Type/危险品类型、产品物料、是否需要尾板（写"需要尾板"/"不需要尾板"、是/否都可以）。
     一个订单的每项信息都要写在一个格子里：内容多就合并单元格或在格内换行，不要拆到下面几行。
     编号格里可以顺带写备注（如"MR26101527，客户收货时间…"），脚本只取开头的编号；
     编号或尾板认不准时，开始前会弹窗问你。
     编号里的备注和"备注"列脚本不会填，会在运行记录里列出来，请自己看一下要不要处理。
     地址会自动整理成只有街道和门牌号再填进 Street，运行记录里会列出"整理后 ← 原文"，请核对。
     AI 整理：询价时会把每单的编号、地址、邮编、城市、国家、尾板、收件人、公司名称
     经开发者的服务器发给 Google Gemini 整理（不发电话和邮箱）。AI 的结果会再经规则检查，
     运行记录里标 [AI] 的是用了 AI 结果。AI 用不了时自动改用规则识别，照常可以用。
     "运费报价(欧元)"列合并的几行会合成一张询价单。
  2. 可以先勾"只预览"看托盘方案对不对，再取消勾选正式运行。
  3. 点"开始"，确认后脚本逐单填写 Enquiry 表单。
     每单填完请在浏览器里检查，然后自己点页面底部的 Enquiry 提交，脚本检测到结果页后自动做下一单。

三、建单
  1. 功能选"建单"，选择从领星导出的出库单 Excel。
  2. 脚本按"Remark/备注"里的 MR 编号，在 Dachser 的 My enquiries 里找报价：
     - 只找到一条：自动点 create
     - 找到多条：弹窗列出，请你在浏览器里自己选一条点 create，然后点"我点好了"
     - 没找到 / 已经 created：跳过
  3. 点 create 后脚本自动填写：收货地址 Street/Country/PCD/City（以领星为准，County 不改）、Name 1/2/3、联系人和电话、
     Order number 后加"+出库单号"、货物内容 battery、危险品 UN3480、上传危险品文件。
  4. 每单填完会弹窗，请在浏览器里检查，确认无误后自己点 Save，再点"继续下一单"。
  5. 结果表会保存在所选 Excel 旁边，文件名是"<Excel名>_建单结果.csv"，
     里面写了每单的处理结果和需要注意的地方。

四、危险品文件
  把危险品文件放进"危险品文件"文件夹（或在窗口里选别的文件夹）。
  文件名（不含扩展名）必须和领星表里的 SKU 完全一样，例如：
      SKU 是 11US2000ZZD-20001  ->  文件名 11US2000ZZD-20001.pdf
  找不到同名文件就不上传，并在运行记录里提醒。

五、产品托盘参数
  产品参数统一放在服务器上，所有人用同一份。每次询价开始前程序会自动下载最新版，
  存到程序文件夹的 pallet_params.json（旧版本备份为 pallet_params.json.bak）；连不上服务器时用这份本机缓存。
  点窗口里的"产品参数"按钮查看和修改：
  - 产品物料编码 = 询价表"产品物料"列里的编码（领星 SKU），忽略大小写和空格，必须完全一致才能匹配。
  - 带 * 的都是必填，包括整托盘实测的高度和重量；整托盘直接用实测值，零散托盘按箱子计算。
  - 检查：码满后的高度不能超过总高上限（默认 220 cm），重量不能超过单托上限（默认 1500 kg）等，
    不合格的不能提交；实测值比按箱子算的还低/还轻时会提醒确认。
  - "通用参数"页是所有产品共用的托盘底板高度/自重和上限，以及查不到产品时的估算参数。
  修改需要审核：新增、修改、删除产品和修改通用参数，点"提交审核"后由开发者审核，通过后才生效。
  提交时可以写一句说明（比如数据来源）。在"我的申请"页可以看到审核结果和驳回原因，待审核的可以撤回。
  没有授权码或连不上服务器时，编辑窗口只能查看，不能修改。

六、WMS 序列号助手（浏览器脚本，可选）
  领星 WMS 复核/验货扫二维码时，一个码里的多个序列号是用逗号隔开的，WMS 要求一行一个。
  装了这个脚本后，扫进序列号框时逗号会自动换成换行，重复的序列号会自动去掉并提示。
  安装（每台电脑一次）：
    1. Chrome 安装扩展 Tampermonkey（Chrome 应用商店搜索 Tampermonkey）。
    2. 打开 chrome://extensions，打开右上角"开发者模式"；
       再点 Tampermonkey 的"详情"，打开"允许用户脚本"（有这个开关时）。
    3. 点浏览器右上角 Tampermonkey 图标 → "添加新脚本"，删掉里面的默认内容，
       用记事本打开程序文件夹里的 xlfp-wms-sn.user.js，全部复制粘贴进去，按 Ctrl+S 保存。
    4. 打开 WMS，点 Tampermonkey 图标 → "设置授权码"，填和本软件相同的授权码。
  使用：
    按单复核页面左上角勾选"支持批量复核（允许输入数量）"，输入出库单号回车、双击 SKU，
    点序列号框弹出多行框，连续扫二维码（可以扫多张），扫完点"提交"。
    每扫完一张码最好自动换行；如果两张码的序列号连在了一起，请把扫码枪设置成扫完加回车。
  授权：每次打开 WMS 会联网验证授权码（之后每小时一次）；授权码无效、被停用或连不上时不转换，
  WMS 本身照常可以手动使用。脚本只改序列号输入框里的文字，不调用 WMS 接口。

七、其它
  - "停止"：当前这一单处理完后停止；如果正在等你操作，请在弹窗里点"结束"。
  - 脚本只填写，不会替你点 Enquiry / Save，提交前请务必检查。
  - 登录信息保存在 dachser_profile 文件夹里，删除它就需要重新登录。
